# 🌐 Tilak Portfolio

A modern developer portfolio built with **React**, **Vite**, and **Tailwind CSS** to showcase my projects, technical skills, and software development journey.

## 🔗 Live Demo

**Website:** https://tilak-portfolio-snowy.vercel.app/

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern UI built with React and Tailwind CSS
- Project showcase with GitHub and live demo links
- Skills and technology overview
- About Me section
- Contact section
- Smooth navigation and clean user experience

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/BIwashbhatarai/TilakPortfolio.git
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
